# Análise de Estratégias de Ensino - EBAC

## 🎯 Objetivo
Este projeto, desenvolvido como parte do curso de Data Science da EBAC, tem como objetivo avaliar estatisticamente a eficácia de duas estratégias de ensino de matemática. Através de testes de hipóteses, buscamos determinar se há uma diferença significativa no desempenho médio dos alunos entre a Estratégia A e a Estratégia B.

## 🛠️ Tecnologias Utilizadas
- Python
- Pandas, NumPy
- SciPy (Stats)
- Matplotlib, Seaborn

## 📊 Metodologia
1. **Definição de Hipóteses**: Estabelecimento da hipótese nula ($H_0$) e alternativa ($H_1$).
2. **Análise Exploratória**: Verificação da distribuição das notas das duas turmas.
3. **Teste Estatístico**: Aplicação do teste t para verificar a significância estatística da diferença entre as médias.
4. **Visualização**: Plotagem da distribuição t destacando a região crítica e o valor observado ($p$-valor).
5. **Conclusão**: Interpretação dos resultados baseada no nível de significância (0,05) para tomada de decisão sobre a superioridade da nova estratégia.
